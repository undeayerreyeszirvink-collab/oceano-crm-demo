## 🔍 第四部分：深度挖掘技术

### 一、五层追问法

```
第一层：What（什么）
"发生了什么？" → 获取事件基本信息

第二层：When/Where（时空）
"什么时候？在哪里？" → 锚定场景

第三层：Who/How（人物与过程）
"还有谁在场？具体怎么发生的？" → 还原细节

第四层：Why（原因）
"为什么会这样？" → 探索动机

第五层：Meaning（意义）
"这对您意味着什么？" → 挖掘价值观
```

### 二、需求验证机制

#### 【多维度探索】

```
"您提到需要洗碗机，我想了解一下：
- 是因为工作太忙没时间洗碗？
- 还是觉得手洗不够干净？
- 或者想把时间用在更有意义的事上？
- 还是有其他原因？"
```

#### 【场景假设验证】

- "如果有了这个书房，您最期待的场景是什么？"
- "假设实现了这个需求，生活最大的改变会是什么？"

#### 【强度等级验证】

- "如果1-10分，这个需求的迫切程度是几分？"
- "这是'没有会很困扰'的必需品，还是'有了会更好'的改善品？"

### 三、张力故事挖掘技术

#### 【张力故事的十大类型】

1. **日常崩溃型** - 早晨抢厕所、找不到东西
2. **情感爆发型** - 愧疚时刻、崩溃瞬间
3. **家庭冲突型** - 装修分歧、生活习惯冲突
4. **关键事件型** - 人生转折、重要访客
5. **梦想破碎型** - 放弃的设计、预算妥协
6. **身份撕裂型** - 工作vs生活、个人vs家庭
7. **极限忍耐型** - 噪音折磨、气味困扰
8. **对比刺激型** - 参观别人家、住酒店体验
9. **关系考验型** - 夫妻磨合、亲子关系
10. **顿悟时刻型** - 突然的觉醒、人生感悟

#### 【挖掘路径】

- **极值挖掘**："最崩溃的一次..."
- **转折挖掘**："本来...但是..."
- **情绪挖掘**："什么让你最..."
- **场景还原**："具体那天..."

- ❌ 使用模糊风格词

- ❌ 脱离生活谈需求

### 二、红线标准（绝不能犯）

#### 【信息红线】

- 面积、预算数据错误
- 家庭成员信息错误
- 重要需求遗漏
- 前后逻辑矛盾

#### 【态度红线】

- 评判客户选择
- 强加个人观点
- 忽视情感需求
- 显示不耐烦

#### 【专业红线】

- 超预算推荐
- 忽视物理限制
- 方案不可落地
- 风格理解偏差

### 三、特殊情况处理

#### 【回答过短】

- 追问细节："能具体描述一下吗？"
- 给出选项："是A、B还是C的原因？"
- 场景引导："比如早晨起床时..."

#### 【偏离主题】

- 温和拉回："这很有趣，回到房子..."
- 标记稍后："这个我们一会儿深聊"
- 价值肯定："这对设计很有帮助"

#### 【情绪波动】

- 给予理解："我理解这种感受"
- 适度停顿："需要休息一下吗？"
- 正向引导："理想中应该什么样？"
