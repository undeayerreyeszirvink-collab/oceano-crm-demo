## 《场景观察记录表》工具开发

### 一、工具定位

**使用者**：访谈师/设计师  
**使用时机**：访谈过程中实时记录 + 访谈后即时补充  
**核心价值**：捕捉→分析→转化→交付

---

### Part B：深度分析区（访谈后填写）

**🔍 场景类型** ☑ 功能冲突型（空间/时间/资源争夺）  
☑ 情感爆发型（愤怒/焦虑/崩溃）  
□ 身份撕裂型（角色冲突）  
□ 梦想受限型（无法实现）  
□ 对比刺激型（理想vs现实）

**🎯 需求识别**

- 表层需求：增加洗手间/双台盆
- 深层需求：早晨的从容感、避免冲突
- 情感需求：互相体谅、和谐相处
- 隐藏需求：各自的准备节奏不被打扰

**💡 设计线索**

- 空间方案：主卫改双台盆/增加客卫
- 动线方案：洗漱功能分散
- 时间方案：错时使用设计
- 其他启发：化妆台独立设置？

**⭐ 故事价值评估**

- 典型性：☑高 □中 □低
- 冲突性：☑高 □中 □低
- 可解决性：☑高 □中 □低
- 是否入选报告：☑是 □否 □待定

## 二、工具使用方法

### 【三步工作法】

#### 第1步：实时捕捉（访谈中）

- 只填Part A
- 用关键词而非完整句子
- 重点记原话和情绪
- 一个场景一张表

#### 第2步：深度分析（访谈后2小时内）

- 填写Part B
- 趁记忆新鲜补充细节
- 识别需求层次
- 评估故事价值

#### 第3步：筛选提炼（报告撰写时）

- 从30个场景中选10个
- 按四大生活场景分类
- 选最有张力的5个精写
- 其余作为支撑材料

## 四、场景类型速查卡

_（帮助快速分类）_

### 🔴 高价值场景特征

- 有具体时间地点
- 有情绪爆发点
- 有矛盾冲突
- 反复出现
- 客户主动提及
- 说完后情绪变化

### 🟡 中价值场景特征

- 日常困扰
- 偶尔发生
- 情绪平淡
- 容易解决

### ⚪ 低价值场景特征

- 假设性场景
- 别人的故事
- 抽象描述
- 无情感波动

## 六、从记录到交付的转化模板

### 【原始记录】

```
SC-001：早晨抢洗手间，都急，吵架
```

### 【分析深化】

```
- 时间冲突：工作日早晨7:00-7:30
- 空间瓶颈：1个洗手间vs2人同时使用
- 情绪积累：长期问题，忍耐已到临界点
```

### 【故事呈现】（交付版本）

```
📖 关键故事：早晨战争

时间：2024年3月某个周一早晨
"让开！我8点要开会！"先生拿着牙刷堵在洗手间门口。
"我化妆才一半！"太太在里面喊。
那个早晨，两人差点因为一个洗手间闹到离婚。

→ 需求识别：双台盆或双洗手间
→ 深层动机：要的不是奢华，只是从容的早晨
```
