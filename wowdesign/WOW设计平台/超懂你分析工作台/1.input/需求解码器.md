## 🎬 场景化解读 Contextual Interpretation

### 场景一：早晨战争

```
客户说："早上太挤了，都抢厕所"

【错误解读】❌
- 需要两个卫生间
- 卫生间太小
- 起床时间安排不合理

【正确解读】✅
- 洗漱功能过度集中
- 缺少功能分流设计
- 需要时间错位方案

【设计回应】
- 主卧增设简易洗漱台
- 干湿分离+功能分区
- 储物就近原则
```

### 场景二：收纳困境

```
客户说："东西太多了，没地方放"

【错误解读】❌
- 东西需要扔掉
- 要买更多柜子
- 房子不够大

【正确解读】✅
- 储物系统不合理
- 垂直空间未利用
- 分类逻辑缺失

【设计回应】
- 全屋收纳系统规划
- 28原则物品管理
- 动线就近收纳
```

### 场景三：风格迷茫

```
客户说："我也不知道喜欢什么风格"

【错误解读】❌
- 随便什么风格都行
- 看设计师发挥
- 没有审美偏好

【正确解读】✅
- 缺少具象参照
- 害怕选错
- 需要引导启发

【设计回应】
- 从生活方式推导
- 用具体元素确认
- 避免风格标签化
```

## ⚠️ 常见误解预防 Misunderstanding Prevention

### 🔴 高风险误解（必须澄清）

|客户表达|常见误解|正确理解|确认话术|
|:--|:--|:--|:--|
|"随便弄弄"|要求不高|不知如何表达|"您最在意哪些方面？"|
|"都听你的"|完全信任|决策疲劳|"我们一起探讨几个方向"|
|"越简单越好"|什么都不要|不要复杂|"简单是指视觉还是使用？"|
|"要实用"|不要美观|功能优先|"实用和美观如何平衡？"|
|"不要太贵"|选最便宜|控制预算|"预算范围是多少？"|

### 🟡 中风险误解（需要确认）

|客户表达|可能理解|深入确认|
|:--|:--|:--|
|"要亮一点"|灯具多 or 颜色浅？|展示采光方案|
|"要大气"|面积大 or 感觉开阔？|用图片确认|
|"要温馨"|暖色 or 软装多？|分别展示对比|
