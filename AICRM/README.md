# AI-Native CRM

> 高端建陶企业 AI Agent 驱动型客户关系管理系统

## 概述

AI-Native CRM 是一个以 AI Agent 为核心的客户关系管理系统，专为高端建筑陶瓷企业设计。与传统 CRM + AI 增强的方式不同，本系统采用 **AI Agent 驱动** 的架构：

- AI Agent 是主角，自动执行大部分工作
- 人主要做决策和监督
- 通过企业微信对话式交互，零学习成本

## 核心功能

### 第一期 MVP（经销商运营）

| 功能模块 | 说明 |
|----------|------|
| 经营分析 | 经销商画像、销售分析、库存状况、门店表现 |
| 异常预警 | 销量下滑、库存积压、回款逾期、长期未活跃 |
| 建议生成 | 补货建议、拜访建议、政策建议、风险提示 |
| 行动追踪 | 创建行动项、分配任务、跟进提醒、完成确认 |

## 技术栈

| 组件 | 技术选型 |
|------|----------|
| Agent 平台 | OpenClaw (自托管) |
| 运行时 | Node.js 22 LTS |
| 语言 | TypeScript 5.x |
| 数据库 | PostgreSQL (Supabase) |
| 消息队列 | BullMQ + Redis |
| Web 框架 | Next.js 14+ (App Router) |
| UI 组件 | shadcn/ui + Tailwind CSS |
| 监控 | Prometheus + Grafana |

## 快速开始

### 前置要求

- Node.js 22 LTS
- PostgreSQL 15+ (或 Supabase 账号)
- Redis 7+ (AOF=everysec)
- 企业微信开发者账号
- 用友 BIP API 访问权限

### 安装

```bash
# 克隆项目
git clone https://github.com/your-org/ai-crm.git
cd ai-crm

# 安装依赖
npm install

# 配置环境变量
cp .env.example .env.local
# 编辑 .env.local 填入实际配置

# 初始化数据库
npm run db:migrate

# 启动开发服务器
npm run dev
```

## 开发指南

### 代码规范

- 使用 TypeScript 严格模式
- 遵循 ESLint + Prettier 配置
- 组件命名使用 PascalCase
- 文件命名使用 kebab-case
- 函数命名使用 camelCase

### 设计规范

详见 [docs/DESIGN.md](docs/DESIGN.md)，包含：

- 颜色系统（主色 slate-900）
- 排版系统
- 交互状态规范
- 响应式设计断点
- Emoji 使用规范

### 安全规范

- CLI 工具调用必须使用 `execFile()` + 参数数组，禁止字符串拼接
- 所有用户输入必须验证和清洗
- 敏感配置使用环境变量，禁止硬编码
