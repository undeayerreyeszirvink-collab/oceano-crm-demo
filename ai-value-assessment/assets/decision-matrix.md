# 评分-决策映射矩阵

> 本文件将评分结果转化为明确的决策建议，避免"评完分不知道怎么办"。

---

## 核心决策矩阵

### 综合得分决策表

| 综合得分 | 决策建议 | 预算区间 | 时间线 | 前置条件 |
|----------|----------|----------|--------|----------|
| **4.5-5.0** | 立即启动，优先级最高 | 100-300万 | 立即启动 | 无 |
| **4.0-4.4** | 立即启动POC | 30-100万 | 1个月内 | 无 |
| **3.5-3.9** | 条件成熟后启动 | 30-80万 | 3个月内 | 补足关键短板 |
| **3.0-3.4** | 谨慎评估，先试点 | 10-30万 | 6个月内 | 降低预期，小范围验证 |
| **2.5-2.9** | 暂缓，补基础 | 暂不投入 | 12个月后 | 数据/组织/流程改善 |
| **<2.5** | 不建议推进 | - | - | 基础条件不具备 |

## 分层决策规则

### 规则1：价值层主导

**当价值层 ≥ 4.0 时**
- 即使就绪度/风险层偏低，也建议推进
- 策略：加大投入补短板，价值足够支撑成本

**当价值层 < 3.0 时**
- 即使就绪度/风险层很好，也不建议推进
- 原因：投入产出比不划算

### 规则2：就绪度门槛

**当就绪度 < 2.5 时**
- 无论价值多高，都建议暂缓
- 原因：基础条件不足，失败风险极高
- 行动：先补数据/技术/组织短板

**当就绪度 ≥ 3.5 时**
- 可快速推进，降低POC周期
- 建议：直接进入小规模生产验证

### 规则3：风险层红线

**当风险层 < 2.0 时**（风险极高）
- 必须暂停，识别并解决核心风险
- 常见原因：数据隐私合规、技术不成熟、变革阻力大

**当风险层 ≥ 4.0 时**（风险极低）
- 可加快推进节奏，扩大投入规模

## 组合决策表

### 高价值 + 低就绪度

| 价值层 | 就绪度 | 风险层 | 决策 |
|--------|--------|--------|------|
| ≥4.0 | <2.5 | 任意 | **先补短板，3个月后重评**<br>投入：20-50万补数据/组织能力 |
| ≥4.0 | 2.5-3.0 | ≥3.0 | **降低方案复杂度，快速POC**<br>选择技术门槛低的方案 |
| ≥4.0 | 2.5-3.0 | <3.0 | **外部合作，降低风险**<br>找成熟供应商，避免自建 |

### 中价值 + 高就绪度

| 价值层 | 就绪度 | 风险层 | 决策 |
|--------|--------|--------|------|
| 3.0-3.5 | ≥3.5 | ≥3.5 | **小规模试点，快速验证**<br>投入10-30万，周期2个月 |
| 3.0-3.5 | ≥3.5 | <3.0 | **识别风险，制定缓解方案**<br>重点关注变革管理/合规 |

### 低价值 + 任意条件

| 价值层 | 就绪度 | 风险层 | 决策 |
|--------|--------|--------|------|
| <3.0 | 任意 | 任意 | **不建议推进**<br>投入产出比不划算 |

## 维度级决策规则

### 数据成熟度决策

| 得分 | 决策 | 行动 |
|------|------|------|
| 1-2 | 暂缓AI项目 | 先做数据治理，6-12个月 |
| 3 | 可启动POC | 边做边补数据，预留数据标注预算 |
| 4-5 | 快速推进 | 数据就绪，可直接训练模型 |

### 组织能力决策

| 得分 | 决策 | 行动 |
|------|------|------|
| 1-2 | 必须外部合作 | 找AI服务商全包，内部培养能力 |
| 3 | 内外结合 | 外部主导，内部配合学习 |
| 4-5 | 可自主实施 | 内部主导，外部顾问支持 |

### 技术复杂度决策（反向）

| 得分 | 决策 | 行动 |
|------|------|------|
| 1-2 | 降低方案复杂度 | 选成熟方案，避免定制开发 |
| 3 | 标准POC流程 | 3个月验证，控制定制范围 |
| 4-5 | 可快速部署 | 直接采购SaaS，1个月上线 |

### 变革阻力决策（反向）

| 得分 | 决策 | 行动 |
|------|------|------|
| 1-2 | 必须做变革管理 | 预留20-30%预算做培训沟通 |
| 3 | 标准变革流程 | 培训+试点+反馈循环 |
| 4-5 | 快速推广 | 用户主动接受，最小化培训 |

## 实施路径模板

### 路径A：快速验证型（综合分4.0+）

```
第1个月：
- 选定场景，组建团队
- 采购/对接AI服务
- 数据准备与标注

第2-3个月：
- POC开发与测试
- 小范围上线验证
- 收集反馈，优化模型

第4个月：
- ROI核算
- 决策是否推广
```

### 路径B：渐进试点型（综合分3.0-3.9）

```
第1-3个月：
- 补短板（数据/组织/流程）
- 选型与方案设计
- 小范围POC

第4-6个月：
- POC验证
- 效果评估
- 决策下一步

第7-12个月：
- 根据POC结果决定推广或暂停
```

### 路径C：基础建设型（综合分<3.0）

```
第1-6个月：
- 数据治理
- 流程标准化
- 组织能力建设

第7-12个月：
- 重新评估
- 决定是否启动AI项目
```

## 特殊场景决策

### 场景1：管理层强推，但评分低

**决策**：小范围POC，管理预期
- 投入：10-20万
- 周期：2个月
- 目标：验证可行性，给管理层数据支撑

### 场景2：评分高，但预算不足

**决策**：分阶段实施
- 第一阶段：最小可行方案（10-30万）
- 用第一阶段收益支撑第二阶段投入

### 场景3：多个场景评分接近

**决策**：优先级排序
1. 价值层最高的
2. 就绪度最高的（快速见效）
3. 风险层最高的（成功率高）

## 使用说明

1. **先看综合分**：确定大方向（推进/暂缓/不做）
2. **再看分层得分**：识别短板和优势
3. **查组合规则**：找到匹配的决策建议
4. **定制实施路径**：基于企业实际情况调整
