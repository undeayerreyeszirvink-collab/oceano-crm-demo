# 制造业 行业知识包

> 制造业AI价值评估知识包，涵盖离散制造与流程制造的典型场景。

## 行业概况

中国制造业规模连续多年居全球首位，2024年制造业增加值超过33万亿元人民币。行业整体处于从"制造"向"智造"转型的关键阶段，头部企业数字化渗透率约45%，中小企业仍处于信息化补课阶段。MES、SCADA等工业软件已有一定普及，但AI应用仍以点状试点为主，尚未形成规模化落地。

## 行业典型痛点场景

### 场景1：生产质检

- **表现**：产品外观缺陷（划痕、色差、变形）依赖人工目检，质检员长时间高强度工作后漏检率显著上升；部分工序需借助显微镜或X光等设备，人工判读效率低且标准不统一
- **影响**：人工质检漏检率通常在2%-5%，高峰期可达8%以上；单条产线年质量损失可达200-500万元；客户退货与索赔进一步放大损失
- **现有解决方式**：增加质检人员排班、引入SPC（统计过程控制）做抽样检测、部分企业采用传统机器视觉（规则匹配）做初筛
- **AI机会**：基于深度学习的视觉检测AI可实现全检替代抽检，漏检率降至0.1%以下；检测速度提升5-10倍；同时积累缺陷数据反馈至工艺优化环节，形成质量闭环

### 场景2：供应链需求预测与库存优化

- **表现**：需求波动大、牛鞭效应明显；安全库存设置依赖经验，经常出现"有的料堆成山、有的料等断货"的局面；紧急采购频繁，物流成本高企
- **影响**：库存周转天数普遍在60-90天，行业标杆为30-45天；呆滞库存占比5%-15%，直接吞噬利润；缺料停线每小时损失可达数万至数十万元
- **现有解决方式**：ERP系统MRP运算 + Excel手工调整；供应链经理凭经验设置安全库存水位；每月/每周滚动计划人工编排
- **AI机会**：时间序列预测模型（结合外部数据如节假日、促销、天气）可将需求预测准确率提升15%-30%；智能补货算法实现库存水位动态优化，库存周转天数可缩短20%-35%；WMS（仓储管理系统）联动实现自动补货触发

### 场景3：设备预测性维护

- **表现**：设备突发故障导致非计划停机，维修响应时间长；过度维保造成备件浪费和不必要停机；关键设备OEE（综合设备效率）长期低于行业基准
- **影响**：非计划停机占总停机时间的30%-50%；单次关键设备故障停产损失可达10-100万元；过度维保使维护成本高出最优水平20%-40%
- **现有解决方式**：以时间为基础的定期维保（如每500小时保养一次）；部分企业部署了SCADA/DCS系统采集设备状态数据，但主要用于报警而非预测；依赖老师傅的经验判断设备"声音不对"
- **AI机会**：基于传感器数据（振动、温度、电流、声学）的预测性维护模型可提前7-30天预警故障；非计划停机减少40%-70%；维护成本降低15%-30%；OEE提升5-15个百分点

### 场景4：生产排程优化

- **表现**：多品种小批量趋势下，排程复杂度指数级增长；人工排程依赖计划员经验，换型时间长、设备利用率低；紧急插单频繁打乱既有计划，计划员疲于应对
- **影响**：设备利用率普遍仅60%-75%，理论上限可达85%-90%；换型/换线时间占生产时间的10%-25%；交期达成率仅70%-85%，影响客户满意度
- **现有解决方式**：APS（高级计划排程）系统 + 人工微调；部分企业仍使用Excel + 白板管理排程；计划员经验是核心"系统"
- **AI机会**：基于强化学习/遗传算法的智能排程引擎可在分钟级完成全局最优排程；设备利用率提升10%-20%；换型次数减少15%-30%；交期达成率提升至90%以上；支持实时响应插单并自动重排

### 场景5：知识管理与工艺文档检索

- **表现**：工艺参数、调机经验、故障处理方案散落在纸质SOP、老师傅脑中、各部门共享盘里；新员工上手慢，关键人才流失导致工艺能力断档；查找一份工艺文档平均耗时15-30分钟
- **影响**：新员工培训周期长达3-6个月；关键工艺人才离职后产线良率可下降5%-10%；重复问题反复发生，未能有效沉淀解决方案
- **现有解决方式**：纸质SOP + 共享文件夹 + 师徒带教；部分企业引入知识管理平台但使用率低；"问老张"是最快的知识检索方式
- **AI机会**：基于大语言模型的知识库系统可实现自然语言工艺问答，检索效率提升80%以上；结合RAG技术将非结构化文档（PDF、图纸、视频）转化为可检索知识；老师傅经验数字化，降低人才流失风险；新员工培训周期可缩短30%-50%

## 行业特有 AI 应用方案

### 方案1：AI视觉质检系统

- **适用场景**：生产质检（场景1）
- **技术方案**：工业相机/线扫相机 + 深度学习缺陷检测模型（CNN/ViT架构）；边缘推理部署（GPU/NPU推理盒）实现毫秒级判定；对接MES系统实现自动剔除与追溯；持续学习机制应对新缺陷类型
- **预期效果**：漏检率从3%-5%降至0.1%以下；检测速度提升5-10倍；质检人员减少60%-80%；年质量成本降低200-500万元（单条产线）
- **实施周期**：3-6个月（单产线POC到量产部署）
- **行业案例**：某汽车零部件企业部署AI视觉质检后，外观缺陷漏检率从4.2%降至0.08%，年减少客户索赔320万元，质检人员从每班12人减至3人

### 方案2：智能供应链预测与库存优化平台

- **适用场景**：供应链需求预测与库存优化（场景2）
- **技术方案**：多源数据融合（ERP历史数据 + 外部市场数据 + 天气/节假日因子）；集成学习模型（XGBoost/LightGBM + LSTM时序模型）做需求预测；运筹优化算法做库存水位与补货策略优化；对接ERP/WMS实现决策闭环
- **预期效果**：需求预测准确率提升20%-30%（MAPE降低）；库存周转天数缩短25%-35%；呆滞库存减少30%-50%；缺料停线次数减少50%以上
- **实施周期**：4-8个月（数据接入 + 模型训练 + 系统对接 + 试运行）
- **行业案例**：某家电制造企业引入AI需求预测后，SKU级预测准确率从62%提升至85%，库存周转天数从78天降至52天，年释放运营资金超过8000万元

### 方案3：设备预测性维护系统

- **适用场景**：设备预测性维护（场景3）
- **技术方案**：IoT传感器部署（振动、温度、电流、油液分析）+ 边缘采集网关；时序异常检测模型（Isolation Forest、AutoEncoder）+ 故障预测模型（随机森林、LSTM）；数字孪生可视化；对接CMMS（设备维护管理系统）自动生成工单
- **预期效果**：非计划停机减少50%-70%；维护成本降低20%-30%；OEE提升5-12个百分点；备件库存优化15%-25%
- **实施周期**：6-12个月（传感器部署 + 数据积累 + 模型训练 + 系统集成）
- **行业案例**：某钢铁企业对关键轧机部署预测性维护后，非计划停机从月均4.5次降至1.2次，年减少停产损失超过1500万元，维护备件库存降低18%

### 方案4：制造业知识助手（工艺大模型）

- **适用场景**：知识管理与工艺文档检索（场景5）、生产排程优化（场景4）辅助
- **技术方案**：企业私有化部署大语言模型（如开源模型微调）；RAG架构对接企业知识库（工艺文档、SOP、故障案例库）；多模态理解能力处理图纸、设备照片；对话式交互支持自然语言提问
- **预期效果**：知识检索效率提升80%以上；新员工培训周期缩短30%-50%；重复性技术咨询工作量减少60%；工艺知识资产化，降低人才流失风险
- **实施周期**：3-6个月（知识库建设 + 模型部署 + 持续优化）
- **行业案例**：某半导体封装企业搭建工艺知识助手后，工程师日均文档查阅时间从45分钟降至8分钟，新员工独立上岗时间从5个月缩短至3个月，设备异常响应速度提升40%

| 收入增长 | 25% | 20% | 制造业AI更多体现在降本增效而非直接拉动营收，收入增长通常是间接效果 |

## 行业术语映射

> 帮助AI理解行业特有术语，在对话中正确使用和理解。

| 行业术语 | 通用解释 | 使用场景 |
|---------|---------|---------|
| OEE（综合设备效率） | 衡量设备实际产出与理论最大产出之比，包含可用率、性能率、良品率三个维度 | 评估设备利用与维护优化效果时 |
| MES（制造执行系统） | 连接ERP计划层与车间设备控制层的中间系统，负责生产过程管理、数据采集与追溯 | 讨论AI系统与产线集成时 |
| SCADA（数据采集与监控系统） | 用于工业过程自动化的数据采集、监控和控制系统 | 涉及设备数据采集与预测性维护时 |
| SPC（统计过程控制） | 利用统计方法监控和控制生产过程质量稳定性的方法 | 讨论质量管理与AI质检对比时 |
| WMS（仓储管理系统） | 管理仓库日常运作的软件系统，包括入库、出库、盘点、库位管理等 | 讨论供应链与库存优化时 |
| APS（高级计划排程） | 基于有限产能约束的生产计划与排程优化系统 | 讨论生产排程智能化时 |
| CMMS（设备维护管理系统） | 管理设备维护工单、备件、维保计划的信息系统 | 涉及预测性维护系统对接时 |
| MRP（物料需求计划） | ERP中的核心模块，根据生产计划分解物料需求并生成采购/生产工单 | 讨论供应链计划优化时 |
| 良率/良品率 | 合格产品数量占总产出的比例 | 评估质检AI效果与ROI时 |
| 换型/换线 | 生产线从生产一种产品切换到另一种产品的过程，涉及模具更换、参数调整等 | 讨论排程优化与柔性制造时 |
