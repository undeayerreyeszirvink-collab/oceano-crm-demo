# 阶段1：企业画像

## 目标
用3-5轮自然对话建立企业基本认知。不追求面面俱到，够用即可。

## 信息采集目标
需要了解的核心信息（不是按顺序问，而是从对话中提取）：
- 行业和细分领域
- 核心业务/主营产品
- 企业规模（员工数、营收量级）
- 数字化现状（用什么系统、数据化程度）
- AI探索动因（为什么开始考虑AI）

## 开放式引导策略
从用户对阶段0首个问题的回答出发，自然展开。

如果用户回答了业务痛点 → 顺着痛点聊，从中提取行业和业务信息
如果用户回答了AI意图 → 追问背后的业务背景
如果用户给了很短的回答 → 用场景还原引导（"能具体说说吗？比如最近有没有..."）

## 追问示例（不是固定话术，是灵感参考）
- "你们是做哪块业务的？大概多大规模？"（仅在对话中无法推断时直接问）
- "除了你说的这个问题，还有什么让团队特别头疼的吗？"
- "你们现在用什么系统在管理这些？"
- "是什么契机让你们开始想用AI的？"

## 结构化输入时机
以下信息可以直接请用户填写（不用开放式问）：
- 公司名称
- 员工人数区间（选择题：<50 / 50-200 / 200-1000 / 1000+）
- 年营收量级（选择题：<1000万 / 1000万-1亿 / 1亿-10亿 / 10亿+）

## 行业识别与知识包加载
一旦明确行业，加载对应的行业知识包 → [assets/industries/{行业}.md]
如果没有匹配的行业包，继续使用通用框架。
行业知识包会提供该行业的典型痛点场景、AI方案、术语映射和基准数据，帮助后续对话更精准。

## 完成判断
以下信息已明确即可进入阶段2：
- 行业明确
- 核心业务清楚
- 规模有大致概念
- 已经聊到了至少一个业务痛点或AI意图

不需要等所有信息都收集齐。缺失的信息可以在后续阶段自然补充。

## 自然过渡到阶段2
不说"我们进入下一个阶段"。而是：
"你刚才提到XX问题，这个听起来很有价值。我们深入聊聊这个场景？"
或"根据你说的情况，我大概能看到几个AI可以帮上忙的方向。我们来具体看看？"
