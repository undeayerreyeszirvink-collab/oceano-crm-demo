# 报告模板

本文件提供三种输出格式的标准模板，供顾问在完成访谈与评分后生成报告使用。

## 统一约束（必遵循）

1. 每个维度分数都要绑定证据ID，来源仅限：访谈原话、文档片段、系统数据。
2. 报告必须输出动作建议：`推进 / 试点 / 暂缓`。
3. 报告必须写明阈值判定理由（Gate-first + 综合分映射）。
4. 报告必须注明行业校准依据和版本信息：
   - Framework Version
   - Calibration Version
   - Trend Version
5. 报告附录必须包含“评分-证据映射表”。

## 模板一：结论摘要卡

### 用途

适用于快速汇报、邮件附件、PPT 封面页或管理层一页纸摘要。

### 进度条渲染说明

| 分数 | 进度条 |
|------|--------|
| 5.0 | `██████████` |
| 4.0–4.9 | `████████░░` |
| 3.0–3.9 | `██████░░░░` |
| 2.0–2.9 | `████░░░░░░` |
| 1.0–1.9 | `██░░░░░░░░` |

评级 emoji 对应关系：
- 5.0 分：🌟 卓越
- 4.0–4.9 分：✅ 推荐
- 3.0–3.9 分：⚡ 有潜力
- 2.0–2.9 分：⚠️ 谨慎
- 1.0–1.9 分：❌ 不建议

### 卡片模板

```
┌─ 🎯 AI应用价值评估结论 ──────────────────┐
│                                           │
│ 企业：{企业名称}                            │
│ 场景：{场景描述}                            │
│ 推荐方案：{方案名称}                        │
│                                           │
│ 综合评级：{评级emoji} {评级文字}（{得分}/5.0）│
│                                           │
│ 价值得分  {进度条} {分数}                   │
│ 就绪度    {进度条} {分数}                   │
│ 风险可控  {进度条} {分数}                   │
│                                           │
│ 💰 预估年化价值：{价值描述}                  │
│ ⏱️ 预估实施周期：{周期}                     │
│ 📈 预估回收期：{回收期}                     │
│                                           │
│ 🔮 AI趋势加成：{趋势修正描述}               │
│                                           │
│ ⚠️ 关键前提：{前提条件}                     │
│ ⚠️ 核心风险：{核心风险}                     │
└───────────────────────────────────────────┘
```

### 占位符说明

| 占位符 | 填写说明 | 示例 |
|--------|----------|------|
| `{企业名称}` | 客户企业全称或简称 | 某制造集团 |
| `{场景描述}` | 10字以内，高度概括 | 质检图像识别自动化 |
| `{方案名称}` | 参考方案目录中的方案名 | 视觉质检 AI 系统 |
| `{评级emoji}` | 见上方评级对应关系 | ✅ |
| `{评级文字}` | 推荐 / 有潜力 / 谨慎 / 不建议 | 推荐 |
| `{得分}` | 综合加权评分，保留一位小数 | 4.2 |
| `{进度条}` | 见上方进度条渲染说明 | `████████░░` |
| `{分数}` | 各维度综合分，保留一位小数 | 4.3 |
| `{价值描述}` | 以"约 X 万元"或"节省 X% 人力"表述 | 约 120 万元 / 节省 40% 质检人力 |
| `{周期}` | 首期上线预计时长 | 3–4 个月 |
| `{回收期}` | 投资回收预估区间 | 12–18 个月 |
| `{趋势修正描述}` | 一句话说明 AI 趋势对哪个维度有正向修正 | 多模态视觉能力提升，技术可行性+0.5 |
| `{前提条件}` | 最关键的一个外部条件 | 历史缺陷图像数量 ≥ 5,000 张 |
| `{核心风险}` | 最高优先级风险，简洁陈述 | 数据标注质量参差不齐 |

## 模板二：结构化评分报告（3,000–5,000 字）

### 用途

适用于向中层管理者或项目负责人汇报，信息密度高，结构清晰，便于决策参考。

### 整体结构

```
1. 评估概要（约300字）
2. 价值评估（约800–1,200字）
3. 就绪度评估（约600–800字）
4. 风险评估（约600–800字）
5. 🔮 AI趋势视角（约300–500字）
6. 实施建议（约400–600字）
```

## 模板三：叙述式咨询报告（8,000–12,000 字）

### 用途

适用于董事会汇报、高管决策参考或正式咨询交付物。以叙述性文字为主，深度分析为辅，帮助决策者全面理解业务背景与 AI 应用价值。

### 整体结构

```
1. 执行摘要（<300字）
2. 企业与业务背景（800–1,200字）
3. 场景深度分析（1,000–1,500字）
4. 推荐方案详述（1,200–1,800字）
5. 价值评估详情（2,000–3,000字）
6. AI趋势与前瞻（800–1,200字）
7. 实施路线图（1,000–1,500字）
8. 附录（500–800字）
```

---

> 字数目标：不超过 300 字（一段话，供百忙的 CEO 阅读）

## 执行摘要

### 评估方法论说明

本报告采用 AI 应用价值评估框架，从三个维度对企业 AI 应用场景进行系统性评估：

**一、价值评估（Value Assessment）**
评估 AI 方案能为企业创造的潜在业务价值，涵盖效率提升、成本节省、收入增长、体验改善四个子维度。
