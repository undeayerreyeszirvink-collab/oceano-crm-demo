# 五大智能体 AI 应用——功能范围与验收标准

> 本附件为合同技术附件，定义乙方交付的五大智能体 AI 应用的功能范围、完成标准及验收条件。

---

## 一、经销商营销智能体

### 1.1 功能范围

| 模块          | 功能说明                                                                           |
| ----------- | ------------------------------------------------------------------------------ |
| 库存上报激励模块    | 提供移动端（APP/小程序）库存上报入口；支持 OCR 拍照识别录入；内置积分/优惠券激励机制，鼓励经销商定期上报库存数据                  |
| AI 营销内容生成模块 | 基于生成式 AI 引擎，根据经销商输入的简要诉求，自动生成海报文案、社交媒体推广帖文及产品短视频脚本；内容可结合当地消费偏好和经销商现有库存产品特点进行优化 |
| 促销策略建议模块    | 结合经销商的库存结构、销售历史和区域市场数据，提供个性化促销建议（如折扣清仓、组合搭售等），并附带数据支撑；支持一键采纳方案并自动生成促销计划        |
| 渠道销售分析与预测模块 | 汇总各经销商销售与库存数据，提供库存预警、销售趋势分析及补货建议；支持总部查看渠道整体健康度看板                               |

### 1.2 验收标准

| 验收项       | 达标条件                               | 说明                                                  |
| --------- | ---------------------------------- | --------------------------------------------------- |
| 功能完整性     | 上述四个模块全部上线并可正常使用                   | 以乙方演示环境或甲方测试环境中功能可操作为准                              |
| 库存上报率     | 已接入的经销商中，≥ 40% 在验收期内至少完成一次库存上报     | 验收期为系统上线后 60 个自然日；上报率受经销商配合度影响，乙方负责技术能力交付，甲方负责推广和运营 |
| AI 内容生成质量 | 生成的营销内容经甲方市场部抽检，≥ 70% 无需人工大幅修改即可使用 | 抽检样本量不少于 30 条；"大幅修改"定义为修改内容超过原文 50%                 |
| 系统可用性     | 系统月度可用率 ≥ 99%（不含甲方基础设施故障及计划内维护窗口）  | 以乙方运维监控数据为准                                         |

## 二、工程报价 & 审批智能体

### 2.1 功能范围

| 模块 | 功能说明 |
|------|---------|
| SKU 聚类检索与竞品对标 | 利用计算机视觉技术，支持上传竞品图片，AI 在欧神诺产品库中检索纹理、花色、规格最接近的 SKU，输出相似度评分和成本优势分析 |
| 动态利润核算与报价推荐 | 综合生产成本、物流运费、垫资成本、返点等因素，AI 自动计算"保本价"和"推荐中标价"，供报价人员参考 |
| 智能审批风控 | AI 预判报价通过率；当利润低于预设红线时自动生成特批理由建议或风险提示，辅助审批决策 |

### 2.2 验收标准

| 验收项 | 达标条件 | 说明 |
|--------|---------|------|
| 功能完整性 | 上述三个模块全部上线并可正常使用 | 以乙方演示环境或甲方测试环境中功能可操作为准 |
| 竞品图片检索准确率 | 在甲方提供的标准测试集上，Top-3 召回率 ≥ 80% | 测试集由甲方提供不少于 50 组竞品-自有产品配对样本；准确率受产品库覆盖范围和图片质量影响 |
| 报价核算准确性 | 系统计算的保本价与甲方财务手工核算结果偏差 ≤ 5% | 抽检不少于 20 笔历史工程订单进行对比验证 |
| 报价响应效率 | 从输入报价参数到系统输出推荐报价，平均耗时 ≤ 30 分钟 | 指系统计算时间，不含人工审核和补充信息的时间 |

## 三、供应链智能协同大脑 (OCEAN-SC Brain)

### 3.1 功能范围

| 模块            | 功能说明                                                             |
| ------------- | ---------------------------------------------------------------- |
| 全渠道库存一盘棋      | 链接工厂仓、中心仓和已接入的核心经销商仓，支持跨仓库存查询与调拨建议；当某地经销商缺货时，AI 计算最优调货路径         |
| 产销协同排程 (S&OP) | 将 CRM 商机及订单数据转化为生产计划建议；AI 自动平衡急单插队与连续生产成本，给出最优排产方案（如同釉料、同模具订单合并） |
| 交付风险预警塔       | 实时监控生产进度和物流轨迹，当检测到可能延期时提前预警，并生成补偿/替代方案建议                         |

### 3.2 验收标准

| 验收项 | 达标条件 | 说明 |
|--------|---------|------|
| 功能完整性 | 上述三个模块全部上线并可正常使用 | 以乙方演示环境或甲方测试环境中功能可操作为准 |
| 数据打通 | 系统成功对接甲方 BIP/ERP 系统及至少 1 个工厂仓的库存数据 | 经销商仓接入取决于经销商配合进度，不作为验收硬性条件；乙方保证技术接口能力就绪 |
| 排产建议可用性 | 系统输出的排产方案经甲方生产部评估，≥ 60% 的方案被采纳或仅需微调后采纳 | 评估期不少于 30 个自然日，样本不少于 15 次排产建议；"微调"定义为调整内容不超过方案总量的 20% |
| 延期预警及时性 | 对已发生延期的订单，系统预警时间平均早于实际延期事件 ≥ 24 小时 | 以验收期内实际发生的延期事件为样本统计 |

## 四、生产管控智能体

### 4.1 功能范围

| 模块 | 功能说明 |
|------|---------|
| 工艺参数监控模块 | 实时采集关键设备和工艺参数数据（温度、压力、配方等），AI 自动校验参数是否在工艺标准范围内；参数异常时及时发出警报并建议调整 |
| 产品质量检测模块 | 基于机器视觉和传感器数据的 AI 质量检测，对产品进行在线质量检测；自动识别瑕疵品或工艺偏差，记录每批次质量数据 |
| 生产状态监控与异常处置模块 | 可视化展示设备运行状态、生产节拍和在制品数量；出现设备故障、瓶颈积压或质量异常时实时预警并推送处置建议 |
| 生产排程优化模块 | 对接订单、库存和产能数据，智能优化生产排产；动态调整生产顺序与节奏，新增插单时评估影响并给出最小扰动的调度方案 |

### 4.2 验收标准

| 验收项 | 达标条件 | 说明 |
|--------|---------|------|
| 功能完整性 | 上述四个模块全部上线并可正常使用 | 以乙方演示环境或甲方测试环境中功能可操作为准 |
| 数据采集覆盖率 | 系统成功接入甲方指定的不少于 1 条试点产线的关键设备数据 | 数据采集依赖甲方提供设备接口和现场条件；产线选择由双方协商确定 |
| 异常预警有效率 | 在试点产线上，系统发出的工艺参数异常预警中，≥ 70% 经甲方生产技术人员确认为有效预警 | 统计周期为上线后 30 个自然日；有效预警指预警内容与实际异常吻合 |
| AI 质检检出率 | 在试点工序上，AI 质检对甲方定义的主要缺陷类型的检出率 ≥ 85% | 以甲方提供的标注测试样本为基准；检出率受样本质量和缺陷类型复杂度影响 |
| 系统看板可用性 | 生产状态监控看板可实时展示试点产线的设备运行状态、在制品数量等关键指标，数据刷新延迟 ≤ 5 分钟 | — |

## 五、采购智能体

### 5.1 功能范围

| 模块 | 功能说明 |
|------|---------|
| 大宗物资价格预测 | 监控化工原料、天然气期货及市场指数等外部数据，AI 预测未来价格走势，给出"按需采购"或"战略囤货"等建议 |
| 供应商风险雷达 | 自动抓取供应商的工商变更、法律诉讼、舆情信息，结合内部交货准时率和质量合格率，生成供应商健康度评分 |
| 备品备件 (MRO) 自动补货 | 根据通用维修备件的消耗速率和库存水位，AI 自动生成采购申请建议，经审批后执行 |

### 5.2 验收标准

| 验收项 | 达标条件 | 说明 |
|--------|---------|------|
| 功能完整性 | 上述三个模块全部上线并可正常使用 | 以乙方演示环境或甲方测试环境中功能可操作为准 |
| 价格预测能力 | 对甲方指定的不少于 3 种核心原材料，系统可输出未来 30 天的价格趋势预测及采购建议 | 价格预测为辅助参考，不保证预测精度达到特定数值；验收以功能可用、输出合理为准 |
| 供应商风险覆盖 | 系统可接入外部工商/司法数据源，对甲方指定的不少于 50 家核心供应商生成健康度评分 | 外部数据源的可用性和数据质量受第三方数据服务商影响 |
| MRO 补货建议准确率 | 系统生成的补货建议经甲方采购部评估，≥ 70% 被认为合理可执行 | 评估样本不少于 30 条补货建议 |

## 六、通用条款

### 6.1 交付范围说明

1. 乙方交付范围为上述五大智能体的**软件系统开发与部署**，包括 AI 模型训练/调优、系统开发、接口对接、测试及上线支持。
2. 硬件设备（如传感器、IoT 网关、服务器等）、第三方软件许可费用、甲方内部系统改造费用不在本合同范围内，由甲方自行承担。
3. 甲方负责提供系统运行所需的基础设施环境、数据接口、业务数据及必要的业务配合（包括但不限于经销商推广、产线现场配合等）。

### 6.2 数据依赖与免责

1. 各智能体的运行效果高度依赖甲方提供的数据质量、数据完整性及数据时效性。因甲方数据质量问题（如数据缺失、错误、不及时更新等）导致的系统输出偏差，不视为乙方交付瑕疵。
2. AI 模型输出结果（包括但不限于预测、建议、推荐）为辅助决策参考，最终业务决策由甲方自行负责。乙方不对因采纳 AI 建议所产生的业务后果承担责任。
3. 涉及经销商数据接入的模块，其接入进度和数据质量取决于经销商配合程度，乙方保证技术接口能力就绪即视为该部分交付达标。

### 6.3 验收流程

1. 各智能体以模块为单位分批验收，每个智能体的全部模块上线后进入 **60 个自然日的试运行期**。
2. 试运行期满后，双方按本附件约定的验收标准进行验收测试。验收结果以双方书面确认的《验收报告》为准。
3. 验收测试中，若个别指标未达标但偏差在 **10% 以内**，乙方应在 **30 个自然日内完成整改**并申请复验。复验通过后视为验收合格。
4. 若验收指标偏差超过 10%，双方应协商确定整改方案和时间表。

### 6.4 效果指标说明

1. 本合同文件中提及的预期业务效果指标（如库存周转天数下降 20%、工程毛利率提升 3%-5%、成交转化率提升 15%-20% 等）为基于行业经验和甲方现状的**合理预期估算**，不构成乙方的承诺或保证。
2. 上述业务效果的实现取决于甲方的组织配合、数据治理、流程变革、经销商参与度等多重因素的综合作用，非乙方软件系统单独可控。
3. 本合同的验收标准以第一至五章中明确列出的**验收标准表格**为准，不以业务效果指标作为验收依据。
