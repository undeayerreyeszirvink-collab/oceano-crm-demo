# IT服务合同审查完整规则集（52条）

本文档包含所有审核规则的完整信息，按一级分类组织。

**必要性标记说明**：
- 必要 = 该业务类型必须有此条款
- 非必要 = 可以没有，但如果有且违规则按指引判定
- 不适用 = 不应出现此条款

**业务类型编号**：①资源服务(框架) ②实施开发(项目) ③软件销售/转售 ④硬件转售 ⑤运维服务 ⑥咨询服务

---

## 一、合同基本信息

### R1 甲方信息
**必要性**：①必要 ②必要 ③必要 ④必要 ⑤必要 ⑥必要
**条款描述**：明确合同甲方的主体信息，包括公司名称、地址、法定代表人、授权代表、统一社会信用代码、联系电话、联系邮箱。
**审核指引**：
1. 甲方公司名称缺失 → 【内容缺失】
2. 合同约定有"法定代表人""授权代表""统一社会信用代码""联系电话""联系邮箱"但未填写 → 【内容缺失】
3. 合同内甲方信息与企业内部系统录入信息不一致 → 【中风险】
4. 合同内甲方称呼/简称与甲方信息不一致（如约定的甲方简称与后文中出现的"需方""委托方""买方"等称呼完全无关联，且与乙方信息也无关联）→ 【中风险】

### R2 乙方信息
**必要性**：①必要 ②必要 ③必要 ④必要 ⑤必要 ⑥必要
**条款描述**：明确合同乙方的主体信息。
**审核指引**：
1. 乙方公司名称缺失 → 【高风险（条款缺失）】
2. 合同约定有"法定代表人""授权代表""统一社会信用代码""联系电话""联系邮箱"但未填写 → 【高风险】
3. 合同内乙方信息与企业内部系统录入信息不一致 → 【中风险】
4. 合同内乙方称呼/简称与乙方信息不一致 → 【中风险】

## 二、合同的签署

### R3 签署时间
**必要性**：①非必要 ②非必要 ③非必要 ④非必要 ⑤非必要 ⑥非必要
**条款描述**：明确合同签订、签署的时间。通常约定为"签订时间：""签署时间："等，不包含单独出现的具体时间。
**审核指引**：
1. 条款没有填写完整具体时间 → 【内容缺失】
2. 签约时间早于合同审核时间 → 【低风险】

### R4 签署地点
**必要性**：①非必要 ②非必要 ③非必要 ④非必要 ⑤非必要 ⑥非必要
**条款描述**：明确合同签署地点。
**审核指引**：
1. 条款没有填写完整具体地点（需详细到市级行政区）→ 【内容缺失】

### R5 签署方式与生效条件
**必要性**：①必要 ②必要 ③必要 ④必要 ⑤必要 ⑥必要
**条款描述**：明确合同产生法律效力所必须满足的签署形式和/或特定事件/时间点。
**审核指引**：
1. 合同没有本条款 → 【条款缺失】
2. 约定合同生效必须达成特定事件和/或时间点（除签字盖章外）→ 【低风险】
**参考范本**：本合同自双方法定代表人或委托代理人签名并加盖单位有效印章（公章或合同专用章）之日起生效。

## 三、有效期/服务期

### R6 有效期
**必要性**：①非必要 ②非必要 ③非必要 ④非必要 ⑤非必要 ⑥非必要
**条款描述**：明确合同整体具有法律约束力的起止时间范围。
**审核指引**：
1. 约定有本条款但没有约定具体期限或具体日期 → 【内容缺失】
2. 有效期起始期限早于审核时间 → 【低风险】
3. 有效期期限大于三年（含）→ 【低风险】

### R7 服务期与续签的约定
**必要性**：①必要 ②非必要 ③非必要 ④非必要 ⑤必要 ⑥非必要
**条款描述**：明确合同项下特定服务需要被履行的具体时间范围。
**审核指引**：
1. 在资源服务（框架）和运维服务类型合同中没有本条款 → 【条款缺失】
2. 约定有本条款但没有约定具体期限或具体日期 → 【内容缺失】
3. 服务期起始日期早于审核时间 → 【低风险】
4. 服务期期限大于三年（含）→ 【低风险】

## 四、合同价款

### R8 合同价款
**必要性**：①非必要 ②必要 ③必要 ④必要 ⑤必要 ⑥必要
**条款描述**：明确合同标的对应价款的数值、构成、币种和价税分离构成。不包含支付时间/方式、违约金、差旅费计算、费用变更规则。
**审核指引**：
1. 非资源服务（框架）类型合同中没有本条款 → 【条款缺失】
2. 软件产品与硬件产品增值税率不是13%，服务类增值税率不是6% → 【低风险】
3. 价款数值大小写不一致 → 【中风险】
4. 价款数值缺少货币单位或数值单位错误 → 【中风险】

### R9 额外费用
**必要性**：①必要 ②非必要 ③非必要 ④非必要 ⑤非必要 ⑥非必要
**条款描述**：明确总价/单价范围外的特定费用（差旅、加班、签证等）由何方承担及计算方式。
**审核指引**：
1. 没有约定差旅费由甲方承担或明确约定需要乙方承担 → 【低风险】
2. 资源服务（框架）合同中没有约定加班费用条款 → 【条款缺失】

### R10 税率变动规则
**必要性**：①非必要 ②非必要 ③非必要 ④非必要 ⑤非必要 ⑥非必要
**条款描述**：明确因法规修改导致税率变动时，合同含税总价/单价变动的规则。
**审核指引**：无

### R11 结算机制（结算周期、结算流程、结算依据、结算公式）
**必要性**：①必要 ②不适用 ③不适用 ④不适用 ⑤不适用 ⑥不适用
**条款描述**：明确周期性结算条款，包含结算周期（月度/季度等）、结算程序、单据要求、结算公式。
**审核指引**：
1. 结算周期实质性超过3个月（如四个月、半年、一年等）→ 【低风险】
2. 合同约定有费用的周期性结算计算公式、绩效结算公式 → 【低风险】

### R12 结算争议的处理
**必要性**：①非必要 ②不适用 ③不适用 ④不适用 ⑤不适用 ⑥不适用
**条款描述**：明确双方未能对结算结果达成一致时的结算规则。
**审核指引**：无

### R13 履约保证金或履约保函
**必要性**：①非必要 ②非必要 ③非必要 ④非必要 ⑤非必要 ⑥非必要
**条款描述**：约定乙方应提供履约保函或支付保证金进行担保。
**审核指引**：
1. 合同约定有履约保证金 → 【低风险】
2. 合同约定有履约保函 → 【中风险】

### R14 支付条件、支付方式、支付期限
**必要性**：①必要 ②必要 ③必要 ④必要 ⑤必要 ⑥必要
**条款描述**：明确支付款项触发条件、支付方式、支付期限。不包含单独金额数字、结算周期、违约金等。
**审核指引**：
1. 没有约定本条款 → 【条款缺失】
2. 约定的支付方式不是现汇、电汇、银行转账和银行承兑汇票 → 【中风险】
3. 支付期限超过30日或20个工作日 → 【低风险】

## 五、知识产权

### R15 客制化开发成果归属
**必要性**：①非必要 ②非必要 ③非必要 ④非必要 ⑤非必要 ⑥非必要
**条款描述**：明确乙方在合同履行过程中的服务成果知识产权归属以及甲方使用权限限制。
**审核指引**：无

### R16 已有知识产权的归属+授权范围+限制
**必要性**：①非必要 ②非必要 ③必要 ④必要 ⑤非必要 ⑥非必要
**条款描述**：说明合同签署前各方已存在的知识产权归属，一般归原权利人所有。
**审核指引**：
1. 合同约定乙方免费授予甲方所有已有知识产权排他的或免费的许可 → 【低风险】

### R17 不侵权承诺、侵权的责任承担
**必要性**：①非必要 ②非必要 ③非必要 ④非必要 ⑤非必要 ⑥非必要
**条款描述**：乙方承诺服务/产品不侵害第三方知识产权，并约定侵权时的责任承担。
**审核指引**：无

## 六、保密与信息安全

### R18 保密范围、保密要求
**必要性**：①非必要 ②非必要 ③非必要 ④非必要 ⑤非必要 ⑥非必要
**条款描述**：约定保密信息的范围、管理措施及披露限制。不包含违反保密义务的违约责任。
**审核指引**：无

### R19 保密期限
**必要性**：①非必要 ②非必要 ③非必要 ④非必要 ⑤非必要 ⑥非必要
**条款描述**：明确履行保密义务的具体期限。
**审核指引**：
1. 保密期限超过五年，或持续有效，或为永久 → 【低风险】

### R20 信息安全要求
**必要性**：①非必要 ②非必要 ③非必要 ④非必要 ⑤非必要 ⑥非必要
**条款描述**：明确合同履行过程中对信息实施全流程管控的要求（传输、存储、使用、查阅环节的技术或管理规范）。
**审核指引**：
1. 合同存在本条款 → 【低风险】

### R21 违反保密或信息安全约定的责任
**必要性**：①非必要 ②非必要 ③非必要 ④非必要 ⑤非必要 ⑥非必要
**条款描述**：明确违反保密义务和信息安全要求时的责任承担规则。
**审核指引**：
1. 违约责任超过合同总金额或订单总金额或阶段结算总金额的20% → 【中风险】
2. 单次违约行为对应的违约金超过2000元 → 【中风险】
3. 违约金按双方合作期间业务往来总金额或框架协议项下已产生金额总额作为计算基数 → 【高风险】
4. 约定赔偿"一切损失""间接损失""全部损失""所有损失" → 【低风险】

## 七、违约责任

### R22 甲方违约责任 - 迟延付款
**必要性**：①必要 ②必要 ③必要 ④必要 ⑤必要 ⑥必要
**条款描述**：明确甲方未按期支付合同款项时应当承担的违约责任。
**审核指引**：
1. 合同没有约定该条款 → 【条款缺失】
2. 与乙方延期交付或延期验收条款不对等（每日违约金比例/上限/赔偿范围不对等）→ 【中风险】（限定在甲方迟延付款与乙方迟延交付/项目中止/终止/迟延验收的对比）
3. 没有约定明确的责任后果（未约定具体比例、金额等）→ 【中风险】

### R23 甲方违约责任 - 项目中止、项目终止、迟延验收
**必要性**：①不适用 ②必要 ③必要 ④必要 ⑤不适用 ⑥不适用
**条款描述**：甲方原因导致项目中止/终止/迟延验收时，甲方承担的责任和乙方免责规则。
**审核指引**：
1. 在必要条款类别中没有约定该条款 → 【条款缺失】
2. 与乙方延期交付或延期验收条款不对等 → 【中风险】
3. 没有约定明确的责任后果 → 【中风险】

### R24 甲方违约责任 - 其他
**必要性**：①非必要 ②非必要 ③非必要 ④非必要 ⑤非必要 ⑥非必要
**条款描述**：不属于"迟延付款""项目中止/终止/迟延验收"的其他甲方违约责任。
**审核指引**：无
**分类关系**：优先识别"迟延付款""项目中止/终止/迟延验收"，无法归入的放入此类。

### R25 乙方违约责任 - 迟延交付、项目中止、项目终止、迟延验收
**必要性**：①不适用 ②非必要 ③非必要 ④非必要 ⑤不适用 ⑥非必要
**条款描述**：乙方原因导致迟延交付或项目中止/终止/迟延验收时的违约责任。
**审核指引**：
1. 违约金按迟延/中止/终止天数计算，单日违约金超过合同总金额的0.3%或阶段款项的1% → 【中风险】
2. 约定赔偿"一切损失""间接损失""全部损失""所有损失" → 【中风险】
3. 约定乙方需要"退还甲方全部已支付款项"及类似表述 → 【中风险】，建议修改为"退还已支付但乙方未交付或交付不合格部分的款项"
4. 没有约定违约金累计上限 → 【中风险】，建议增加"因此产生的违约金累计上限不得超过合同总金额的X%"

### R26 乙方违约责任 - 不符合验收标准
**必要性**：①不适用 ②非必要 ③非必要 ④非必要 ⑤非必要 ⑥非必要
**条款描述**：乙方提交的服务成果或产品不符合验收标准时的违约责任。
**审核指引**：
1. 验收不合格没有约定整改机会 → 【中风险】，建议增加整改机会
2. 约定赔偿"一切损失""间接损失""全部损失""所有损失" → 【中风险】
3. 约定乙方需要"退还甲方全部已支付款项" → 【中风险】，建议修改为"退还已支付但交付不合格部分的款项"

### R27 乙方违约责任 - 未按约定要求投入资源/资源稳定性要求
**必要性**：①非必要 ②非必要 ③不适用 ④不适用 ⑤非必要 ⑥非必要
**条款描述**：乙方未按合同约定投入资源时的违约责任。
**审核指引**：
1. 未按约定时间/要求投入资源，逾期一日违约金超过2000元 → 【低风险】
2. 未经甲方许可擅自更换人员，违约金超过5000元 → 【低风险】

### R28 乙方违约责任 - 其他
**必要性**：①非必要 ②非必要 ③非必要 ④非必要 ⑤非必要 ⑥非必要
**条款描述**：不属于上述类型的其他乙方违约责任。
**审核指引**：
1. 按违约次数处以违约金，每次超过2000元但不超过5000元 → 【低风险】；每次超过5000元 → 【中风险】
2. 按迟延天数或违约持续天数支付违约金，每日超过合同总金额的0.5% → 【中风险】
3. 约定乙方需要"退还甲方全部已支付款项" → 【中风险】
**分类关系**：优先识别"迟延交付/项目中止/终止/迟延验收""不符合验收标准""未按约定投入资源"，无法归入的放入此类。

### R29 违约责任通用约定
**必要性**：①非必要 ②非必要 ③非必要 ④非必要 ⑤非必要 ⑥非必要
**条款描述**：明确违约责任承担的形式、限制、要求，包含违约金上限、损失范围、违约金扣除方式、免责条件。不包括具体违约行为的违约责任。
**审核指引**：
1. 约定甲方可以直接在尚未支付的款项中扣除乙方违约金 → 【低风险】

## 八、合同变更与终止

### R30 变更程序与变更形式
**必要性**：①非必要 ②非必要 ③非必要 ④非必要 ⑤非必要 ⑥非必要
**条款描述**：明确合同条款变更的程序、形式及生效条件。
**审核指引**：
1. 约定变更需要另行签署书面协议才生效 → 【低风险】
2. 约定授权代表/项目负责人/项目经理签署的变更文件有法律效力，但合同未约定相应人员 → 【低风险】
3. 约定未经双方协商一致即可变更 → 【高风险】
4. 约定一方提出变更另一方必须接受或一定期限内未回复视为接受 → 【高风险】

### R31 解除/终止
**必要性**：①非必要 ②非必要 ③非必要 ④非必要 ⑤非必要 ⑥非必要
**条款描述**：明确一方在满足条件下可以无责解除或终止合同的条款。不包含因具体违约行为或不可抗力导致的解除/终止。
**审核指引**：
1. 甲方解除合同条件过于宽松（如仅需提前N日通知即可解除）→ 【中风险】
2. 甲方解除合同后乙方责任过重 → 【中风险】，责任过重包括：
   - 乙方违约金超过合同总金额10%或框架协议已产生金额总额10%
   - 乙方需赔偿"一切损失""间接损失""全部损失""所有损失"

## 十、合规性义务

### R33 廉洁要求
**必要性**：①非必要 ②非必要 ③非必要 ④非必要 ⑤非必要 ⑥非必要
