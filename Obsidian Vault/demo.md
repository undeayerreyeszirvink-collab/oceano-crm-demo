> 目标：把“周成本看板”升级为可产品化、可复制交付的 **Profit Command Center（利润作战指挥舱）**。

## 9.1 信息架构（IA）与页面结构

- **P0 首页：董事会/CEO总控舱**（5分钟看懂：方向/风险/现金）
    
- **P1 利润归因作战页**（异常→归因→动作→责任→复盘）
    
- **P2 现金流释放战场**（库存结构、释放路径、调拨效率）
    
- **P3 供应链&生产战场（含MES）**（产线状态、良品率、能耗、停机、排产模拟）

- **P6 数据治理与口径中心**（指标口径、主数据、质量评分、血缘）
    
- **P7 任务中心（闭环）**（预警→派单→执行→结果→沉淀为规则/技能）

### B）组件库（Component Library）

#### 1）KPI Card（战略指标卡）

- Variants：`normal / warning / danger`
    
- Slots：
    
    - Title
        
    - Value（大数字）
        
    - Delta（WoW环比）
        
    - Sparkline（7/28天）
        
    - Threshold（红线虚线）
        
    - Tooltip（口径）
        

#### 2）Profit Tree（利润归因树）

- 结构：利润 → 收入/成本 → 材料/能耗/人工/制造费用/报废/运费 → 明细
    
- 支持：展开/折叠、Top N聚合、点击下钻至订单/批次
    

#### 3）Alert Feed（预警流）

- 自动排序：`影响金额×概率×可干预性`
    
- 状态：`open / acknowledged / in-progress / closed`
    
- 一键动作：派单、指派责任人、设置截止时间、生成复盘
    

#### 4）Drilldown Table（穿透表格）

- 固定列：对象（订单/SKU/基地/供应商）
    
- 指标列：毛利、单位成本、偏差、影响金额、责任归属
    
- 行内展开：展示成本拆解mini-chart
    

#### 5）Scenario Simulator（情景模拟器）

- 输入：
    
    - 调价（±%）
        
    - 换产/插单
        
    - 调拨路径
        
    - 采购价格变动
        
- 输出：交期影响、成本影响、利润影响、风险提示
    

#### 6）Data Quality Badge（数据质量徽章）

- 维度：完整性/一致性/及时性/准确性
    
- 评分：0-100（显示分位与趋势）

## 0. 执行摘要（Executive Summary）

- 制造业进入“决策复杂度爆炸时代”
    
- 传统ERP/MES/BI无法解决“边际决策问题”
    
- Agent + Ontology + Skills = 新一代决策基础设施
    

## 1. 制造业决策的三大断裂

1. 数据存在，但决策不可计算
    
2. 规则存在，但无法动态重组
    
3. 报表存在，但无法行动闭环

## 2. 方法论核心：O-S-A 三层模型

O = Ontology（业务本体） S = Skills（可组合决策算法） A = Agent（对话式编排引擎）

形成： 数据 → 本体结构化 → Skills模块化 → Agent编排 → 决策输出 → 执行闭环
## 一句话总结

**你左边有一套 “你的数据名字”，

右边系统有一套 “它要的名字”，

映射 = 告诉系统：哪个对哪个。**
你现在要使用 **pricing.simulate（价格模拟）** 这个功能。

### 系统（右边）说：

“我要算价格，**必须要你给我 3 个东西**：

1. 商品 ID
2. 数量
3. 折扣率”

### 你的数据（左边）叫：

1. sku_id
2. qty
3. discount_rate
