## 2. 硬件模块化架构 (Modular Hardware Architecture)

### 2.1 核心架构：1+N+X 模型

- **1 个可升级核心中枢 (Brain)**：标准化接口的计算核心，支持换板升级
- **N 个功能模组 (Modules)**：即插即用的功能扩展单元
- **X 个外设生态 (Peripherals)**：通过 Matter 协议连接的第三方智能卫浴设备

### 2.2 核心中枢 (Core Hub) 规格

| 组件 | Lite 版 | Pro 版 | Max 版 | 接口标准 |
|------|---------|--------|--------|----------|
| **主控芯片** | 双核 ARM Cortex-A7 (1.2GHz) | 四核 ARM Cortex-A55 (1.8GHz) | 八核 ARM Cortex-A78 + NPU (6 TOPS) | 标准化 PCIe 接口板卡 |
| **内存/存储** | 512MB RAM / 4GB eMMC | 1GB RAM / 8GB eMMC | 4GB RAM / 32GB eMMC + 可扩展 SD | - |
| **Matter 协议栈** | Thread + Wi-Fi 双模 | Thread + Wi-Fi + Ethernet | Thread + Wi-Fi + Ethernet + Zigbee 兼容 | 内置天线 + 外置天线接口 |
| **防水等级** | IPX4 | IPX5 | IPX6 | 全密封铝合金机身 |
| **升级方式** | 整板更换 (标准化 120×80mm 板型) | 整板更换 + OTA | 整板更换 + OTA + 算力扩展卡 | 滑轨式快拆结构 |

| 传感器类型 | Lite | Pro | Max | 精度要求 |
|------------|------|-----|-----|----------|

  - Pro: 最多 50 个 Matter 设备  
  - Max: 最多 128 个 Matter 设备 + 场景自动化引擎

- **核心板升级**：用户可在使用 2 年后购买新款核心板自行更换 (成本 ¥200-800)，保留原有传感器和外壳投资

**软件升级策略**：
- 购买更高级 AI 订阅后，通过 OTA 解锁本地计算资源 (如 Max 版硬件锁定部分算力，订阅后激活)

## 6. 技术接口与选型标准

### 6.1 核心中枢接口定义

| 接口类型 | 数量 | 用途 | 物理规格 |
|----------|------|------|----------|
| **主电源** | 1 | 12V/3A DC 输入 | 防水 DC 接口 (IP67) |
| **模组扩展口** | 2 | 音频/显示模组 | FPC 40pin (0.5mm 间距)，支持 I2S/MIPI/USB2.0 |
| **传感器总线** | 4 | 环境传感器 | I2C/UART 复用，4pin 防水接插件 (JST SM04B) |
| **Matter 天线** | 2 | Wi-Fi + Thread | 内置 PCB 天线 + 外置 SMA 接口 (可选高增益天线) |
| **调试接口** | 1 | 工厂维护/售后 | 磁吸触点 (Pogo Pin)，支持 OTA 与串口调试 |
| **用户接口** | 1 | 紧急重置/配网 | 防水机械按键 (长按 10s Matter 重置) |

### 6.2 模块选型详细标准

**音频输入模组**：
- 声学指标：频率响应 100Hz-16kHz，灵敏度 -38dBV/Pa，AOP 120dB
- 环境适应：支持 -10°C 至 60°C 工作温度，防冷凝设计
- 认证要求：需通过 Alexa Voice Service 或 Google Assistant 认证 (如适用)

**显示模组**：
- 光学指标：镜面反射率 ≥ 70%，透射率 ≥ 40%，雾度 < 1%
- 加热防雾：PTC 加热膜，3 分钟除雾 (ΔT=25°C 环境)
- 触控：支持湿手操作 (水膜厚度 < 2mm 下正常响应)

**环境感知模组**：
- 温湿度：防水透气膜保护 (ePTFE)，响应时间 < 10 秒
- 雷达：符合 ETSI EN 302 567 (欧洲) / FCC 15.255 (美国) 标准

## 7. OTA 与可维护性设计

### 7.1 OTA 策略

- **分区设计**：A/B 分区，更新失败自动回滚
- **网络策略**：
  - Lite：仅支持 Wi-Fi OTA，包大小 < 50MB
  - Pro/Max：支持断点续传，差分更新，包大小可达 500MB (AI 模型更新)
- **安全**：签名验证 + 加密传输 (TLS 1.3)

### 7.2 维护设计

- **模块化更换**：核心板、音频板、传感器板均为独立 PCB，标准螺丝刀即可更换
- **故障诊断**：通过 Matter 协议上报设备健康状态 (CPU 温度、内存占用、传感器离线状态)
- **生命周期承诺**：保证核心接口 5 年不变，模组配件 3 年供应保障
