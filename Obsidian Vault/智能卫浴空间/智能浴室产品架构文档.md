**适用范围**：面向消费级智能浴室柜产品线（价格梯度：599元基础款、1999元标准款、5999元旗舰款）  

### 1. 文档目的与范围
本文档基于“智能浴室核心中枢硬件设计需求文档”进行扩展，完整定义智能浴室产品的整体架构。  
核心目标：通过**高度模块化硬件 + 分级AI软件订阅 + Matter协议**，实现同一核心中枢平台支撑三个价格梯度的产品，实现快速迭代、成本可控、功能差异化。  
Matter协议作为统一控制层，使智能浴室柜成为整个智能卫浴生态的中心，可直接控制智能马桶、智能淋浴、智能空调、智能水龙头、智能浴霸、智能镜前灯等第三方Matter设备。

### 2. 产品定位与分级策略
- **基础款（599元）**：入门语音交互 + 基础环境感知 + Matter控制基础设备。面向预算用户。
- **标准款（1999元）**：高清镜面显示 + 优质音频 + 增强AI能力。面向家庭主流用户。
- **旗舰款（5999元）**：全模块顶级配置 + 顶级AI订阅 + 多设备联动场景。面向高端用户。

**模块化设计原则**：
- 核心中枢主板（SoC + Matter/Thread）为**唯一公共平台**，所有等级共用。
- 其他模块采用**标准插拔接口**（统一40-pin或M.2接口），支持工厂/用户后期升级换板。
- 软件层面通过License密钥激活不同功能与订阅等级，实现“一硬件多软件”。

### 3. 整体系统架构
```
[云端服务层] ←→ [Matter控制器 + AI云] 
          ↑
[智能浴室柜核心中枢] ←→ Matter/Thread 网络
          │
   ┌──────┼──────┬──────┐
   │     模块     │      │
   └──────┼──────┴──────┘
          ↓
[外部智能卫浴设备]（马桶、淋浴、空调、水龙头等）
```

- **核心中枢**：主控大脑（含Wi-Fi 6 + Thread Border Router + Bluetooth 5.3）。
- **模块层**：可热插拔的子模块。
- **网络层**：Matter 1.3+ 标准（支持桥接Zigbee/Bluetooth设备）。
- **云端层**：分级AI订阅服务（基础/标准/旗舰）。

### 4. 硬件架构与模块化配置表

#### 4.1 核心中枢硬件（所有等级共用）
- 主控SoC：支持Matter/Thread的四核A55或同等AIoT芯片（预留NPU 2TOPS以上）。
- 存储：最低4GB RAM + 32GB eMMC（旗舰可扩展至8GB+128GB）。
- 接口：统一40-pin扩展总线（I2S、I2C、SPI、USB、GPIO、MIPI DSI、CSI）。
- 电源管理：5V/12V自适应，支持PoE可选。
- 防护：IPX7级防水防潮，整机通过-20℃~60℃、95%RH长期测试。
- 支持OTA固件升级 + 模块热识别。

### 5. 软件架构与AI订阅分级

#### 5.1 软件分层
- **底层**：RTOS + Matter SDK（开源Chip + OpenThread）。
- **中间层**：本地AI引擎（离线语音唤醒 + 简单意图识别）。
- **上层**：云端AI服务（通过MQTT/WebSocket与核心中枢通信）。
- **应用层**：浴室专属App（镜面UI + 手机App）。

#### 5.2 AI软件订阅分级（按年/月付费）

| 订阅等级 | 月费（示例） | 包含能力 | 对应硬件等级 |
|----------|--------------|----------|--------------|
| **基础AI** (免费/包含在硬件) | 0元 | 本地语音唤醒 + 简单天气/音乐 + Matter基本控制（开/关） | 基础款默认 |
| **标准AI** | 19元/月 | 云端大模型语音对话 + 场景联动（“洗澡模式”自动调温/灯光） + 健康提醒（洗澡时长） | 标准款默认 |
| **旗舰AI** | 49元/月 | 顶级大模型（多轮对话+个性化） + AI健康监测（皮肤水分/体温趋势） + 自动生成“浴室日记” + 第三方设备深度控制 + 家庭成员语音识别 | 旗舰款默认，可向下兼容 |

- 订阅通过设备SN+云账号绑定，支持随时升级。
- 离线模式始终可用（基础AI），确保断网不瘫痪。

### 6. Matter控制能力
核心中枢默认作为**Matter控制器 + Thread Border Router**：
- 可直接添加并控制：智能马桶（冲洗/坐温/烘干）、智能淋浴（水温/流量）、智能空调/浴霸、新风系统、智能水龙头（感应/恒温）、智能镜前灯、浴室地暖等。
- 支持多厂商设备（小米、华为、欧瑞宝、Kohler等Matter认证产品）。
- 场景示例：
  - “起床洗漱”：语音唤醒 → 自动开灯+调温+播放新闻。
  - “儿童模式”：限制水温+播放儿歌。

### 7. 关键设计要求（继承并扩展原硬件文档）
- **防护**：全模块IPX7，核心中枢采用三防漆+纳米涂层。
- **可维护性**：核心中枢支持“升级换板”（5分钟拆装），其他模块标准化接口。
- **功耗**：待机<2W，整机峰值<30W（旗舰）。
- **尺寸与布局**：核心中枢尺寸≤120×80×20mm，安装在浴室柜后背板固定位置，不影响柜体美观。
- **可靠性**：MTBF>50,000小时，-20~60℃、95%RH全工况验证。
- **安全性**：本地端到端加密、Matter设备认证、摄像头物理遮挡、隐私模式。

### 8. 模块选型统一标准（所有等级通用）
- 性能指标：详见第4.2表。
- 接口标准：统一40-pin + M.2 Key-B（支持热插拔识别）。
- 功耗：单模块<5W。
- 可靠性：-20~60℃、95%RH、10年寿命。
- 外观：镜面/白色/黑色可选，尺寸与浴室柜深度适配（≤25mm厚）。

### 9. 升级与迭代路线
- **硬件迭代**：新一代核心中枢（SoC升级）可直接替换，老模块全部兼容。
- **软件迭代**：OTA支持差分升级，订阅用户自动获得新AI能力。
- **生态扩展**：未来可开放“模块SDK”，第三方可开发新模块（如香薰模块、健康秤模块）。
