# GEO Skill — 生成式引擎优化（含中国市场适配）

## 概述

基于 Dan Koe 实战验证的 GEO（Generative Engine Optimization）方法论打造的 Claude Code 技能，并扩展支持中国市场（百度、知乎、微信生态）。Dan Koe 运用这套方法在 3 个月内将自然流量从不足 10 万提升至超过 1000 万，其中 Google Gemini 贡献了 54% 的新增流量。

## 核心理念

GEO 代表了从传统 SEO 到生成式引擎优化的范式转变。让你的内容被 AI 引擎（Google Gemini、百度文心一言等）视为权威可信的优质来源，使其主动向用户推荐你。

## 五步工作流程

0. **受众与目标定义** — 明确目标受众、业务场景与核心关键词策略
1. **问题挖掘** — 使用 Perplexity / 百度指数挖掘用户真实搜索问题
2. **内容重构** — 使用 Claude 重构内容结构与语义，ChatGPT 交叉验证质量
3. **技术优化** — Schema Markup 结构化数据，IndexNow 即时索引（百度站长平台推送）
4. **权威建设** — Reddit、Quora、Medium 及知乎、微信公众号等平台跨平台布局

## 适用场景

- **Personal Brand / 知识创作者** — 个人品牌与内容 IP 的 AI 搜索可见性
- **SaaS / B2B 企业** — 产品与技术内容的生成式引擎权威建设
- **E-commerce / DTC 品牌** — 商品与品牌内容的 AI 推荐优化
- **中国市场业务** — 百度、知乎、微信生态的本土化 GEO 策略
